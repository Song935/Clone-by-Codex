# 시작하기

이 프로그램은 **사람과 AI 에이전트가 함께 도면을 작성하는 CAD**의 공개 개발 미리보기입니다.

## 실행

배포 ZIP을 풀고 `Install.cmd`를 실행하면 현재 사용자에게 설치됩니다. 또는 `app/CloneCad.Desktop.exe`를 직접 실행합니다. .NET 런타임은 배포판에 포함됩니다.

소스 실행은 .NET 10 SDK 설치 후 `scripts/run.ps1`을 사용합니다. 개발 PC에서는 `D:\Song\.tools\dotnet10`의 SDK도 자동으로 찾습니다.

1. **검증 도면**으로 합성 기초 단면도를 엽니다.
2. 휠로 확대·축소, 중간 버튼 드래그로 화면을 이동합니다.
3. 객체를 클릭해 추가 선택합니다. Shift+클릭은 해제합니다.
4. 하단 명령창에 `RECTANG 0,0 600,900` 등을 입력합니다.
5. `.cbcad`로 저장하면 치수·해치 연결 정보가 유지됩니다.
6. DXF로 교환하거나 출력 미리보기를 확인한 뒤 PDF로 저장합니다.

F3은 스냅, F8은 직교, F10은 15도 간격 각도 추적입니다. Esc는 명령 취소·선택 해제, Enter는 확정·직전 명령 반복, Ctrl+Z/Y는 실행 취소·다시 실행입니다.

선택 후 MOVE·COPY 등의 명령을 실행하고 기준점·끝점을 입력합니다. 명령창에서 `x,y`, `@dx,dy`, `@거리<각도`를 사용할 수 있습니다. ARC는 중심점→시작점→끝 방향점 순서입니다. TEXT에서 여러 줄은 속성 편집의 `\P`로 입력합니다.

치수 명령은 DIMALIGNED, DIMLINEAR, DIMANGULAR, DIMRADIUS, DIMDIAMETER입니다. 선 하나를 선택하고 DIMALIGNED를 실행하면 해당 선과 연결된 치수를 만듭니다. 반지름·지름 치수는 원·호를 먼저 선택합니다. DIMSTYLE은 공통 치수 스타일을 엽니다.

## AI 작도

오른쪽 **Anthropic 연결 설정**에서 사용자 API 키와 사용 가능한 모델 ID를 입력하고 저장합니다. 키는 Windows 자격 증명 저장소의 `CloneCad/Anthropic`에 저장됩니다. 모델 사용료는 사용자의 API 계정에 부과됩니다.

예: `폭 600mm, 높이 900mm 사각형을 그리고 중심에 지름 100mm 원을 만들어줘.`

AI가 필요한 도면 정보를 조회한 뒤 변경안을 만듭니다. 초록색은 추가·수정, 빨간색은 삭제 제안입니다. **도면에 적용**을 눌러야 실제 도면이 바뀝니다. 적용한 작업은 Ctrl+Z 한 번으로 되돌립니다. 사람의 편집으로 도면 버전이 달라지면 이전 변경안은 적용할 수 없습니다.

외부 에이전트는 연결 패널의 **외부 에이전트 연결 정보 복사**를 사용합니다. 현재 실행한 CAD 인스턴스를 가리키므로 CAD 재시작 후 다시 복사해야 합니다. 배포판에는 `app/mcp/CloneCad.Mcp.exe`가 포함됩니다.

## 평가 시 알아둘 점

DXF는 지원 객체만 가져옵니다. 미지원 객체와 대체되는 글꼴·선종류를 확인한 뒤 부분 가져오기를 선택하세요. 원본 DXF는 변경하지 않습니다. 도면 단위와 치수, PDF 축척을 직접 확인하세요.

이 버전은 실무 대체품으로 검증된 상태가 아닙니다. 실제 Anthropic 호출과 별도 Windows 11 PC 설치는 아직 사용자 환경 검증이 필요합니다. 자세한 기능 제한은 README와 VERIFICATION에 기록합니다.
